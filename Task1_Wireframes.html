02 / 04

Design Annotations

01
Navigation Pattern
Bottom tab bar with 4 primary routes: Home, Search, Orders, Profile. Active state uses filled icon + label highlight. Persistent across all main screens.
02
Search & Filters
Sticky search bar with location context. Horizontal chip scroll for category filtering. Debounced input triggers live results. Filter sheet modal on tap.
03
Cart Persistence
Cart count badge on bottom nav. Floating CTA on restaurant screen. Cart persists across sessions using local storage. Conflict alert if switching restaurants.
04
Live Tracking
Real-time rider location via WebSocket. 4-step status progress. Estimated arrival countdown. One-tap call/chat with rider. Push notifications at each milestone.
