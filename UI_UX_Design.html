Design Decisions

✓Hero card uses a gradient to draw attention to the most critical metric (progress)
✓Color-coded priority badges (blue=high, amber=medium, green=done) allow instant scanning
✓Bottom navigation kept to 4 items — respects thumb zone ergonomics on mobile
✓Completed tasks use strikethrough + muted color for clear visual state differentiation
✓Avatar initials in the header provide user identity without loading delays

Spacing & Layout System

Grid: 8px base unit. Padding: 16px screen edges. Card corner radius: 16px. Typography scale: 12 → 14 → 16 → 20 → 24px. Navigation height: 64px (safe area aware).
